- **#2 "Staff Writer" media hack — RUN THIS. Best fit by far.** It's the exact distribution engine for the pitch + quotes above. Search "staff writer" / "contributor" in LinkedIn People, filter to leadership/HR/business publications, connect with ~5/week, lead with a useful comment on their work, then send the pitch. - **#3 LinkedIn Live + lead-magnet — STRONG, more effort.** Host James on "Why your leadership team feels disconnected — and the data on fixing it." The "workbook bait" is already built: offer the report, or a one-page "12 questions before your next offsite" checklist. DM attendees the asset + one personal question. Good pipeline generator once the posting cadence is running.
- **#1 Ad Library — WEAK fit, skip as a core play.** That tactic is built for freelancers selling services to companies that advertise. You sell $25k–$500k retreats, not influencer packages. Only use it as *competitive intel*: search "executive offsite / leadership development" to see who's advertising to your buyers and how they position. Don't build the phase around it.

**Sequence:** post the report (#2 audience warm-up) → run the staff-writer + HARO engine for 3–4 weeks → schedule one LinkedIn Live with the report as the magnet.
